Number of times the indicator was seen, for instance $result.count$ of a stats search. Defaults to 1.
Start of the sighting, as an epoch in seconds or an ISO 8601 date, for instance $result.first_seen$. Defaults to the event time.
End of the sighting, as an epoch in seconds or an ISO 8601 date, for instance $result.last_seen$. Defaults to the event time.
Score given to the sighted indicator, from 0 to 100, for instance 100. Empty leaves the score unchanged.
The indicator stays valid that many days after the sighting, for instance 90 for three months. Only ever extends the validity. Empty leaves it unchanged.
Name of a result field whose values are added to the labels, for instance labels as returned by opencti_lookup. Leave empty to add none.
